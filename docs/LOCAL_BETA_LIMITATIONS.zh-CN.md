# 当前清单预览的限制

本轮尚未达到完整测试版或开源发布门槛。适用范围是本机单用户、合成资料的订单变更建议；新清单不执行订单、预占库存或连接ERP。旧FIXTURE演示另外有批准/提交入口，不能与真实导入自动互转。

真实模型首条浏览器流程和开发小批已经运行，但临时参考未获独立真人确认，不能发布正式准确率。固定738c909的两条开发例复测中，换款三次均得到正确数量；PDF两次仍误澄清，一次有效差异正确但原始提案含冗余零差量动作。没有具体模型快照，不能推广为一般正确率。保留PDF及OCR尺码L误读限制，人工纠正不算模型成功；暂停针对单条PDF反复调参，优先人工核对。风险保留样本被开发AI看过，需要新的隔离风险集和明确评分后才能重做正式风险验收。

只证明导入事实及采用字段的有限一致性，未证明快照是真实最新ERP、完整来源父链或共享依赖。缺已发/已裁、库存、版本或归属保持未知，不自动当零或认证历史。所有清单确认仍是建议，外部执行前须核对最新事实。

实际界面操作覆盖桌面Chromium与约688px窄窗口；没有Windows/macOS、手机触屏、独立陌生用户或生产性能承诺。中文图片依赖本地Tesseract语言数据；表格不是任意Excel布局推断器，宏/公式/外链、XLS、XLSM、语音及扫描PDF自动读取不支持。

图片数字低分或检查不可用时，须对照原图完整转录；旧图片缺检查记录时，可新建任务重读或完整转录。直接采用图片 OCR 时，即便没有识别到数字，也须单独声明已核对编号、数量、金额、日期和漏读内容。低分可能误拦正确文字，也可能漏掉高分错误或完全未读出的数字；勾选不证明识别正确。一轮合成图片浏览器脚本曾在保存人工提案后的组合断言失败；当时没有完整中间状态，后续等待、延迟、负载和 wheel 复测未重现，原因仍未确定。

没有身份认证、订单级授权或多人审批身份，不得开放共享服务。密钥只在服务端配置，Host/来源检查不是认证。费用上限只约束同一账本下的调用，不能约束其他程序消费同一密钥。

原件持久存储但不自动清理。停服备份需数据库和原件/预览一起验证；通用备份恢复仍要求原绝对路径，没有在线备份或任意路径迁移支持。针对文档中指定版本和 SQLite 的回退，可按[数字复核回退说明](beta/INPUT_SUPPORT.zh-CN.md)制作并校验独立数据库与原件/预览副本，不代表其他版本或生产环境均可恢复。原件丢失/变化会拒绝下载；错误下载目前可能显示结构化JSON，返回任务并打开原件页恢复。

现有开发历史有内部路径和个人提交邮箱，不能直接改为公开。当前仍是私有开发预览；许可证归属、维护者联系方式、正式模型指标、3–5分钟录屏及独立用户试用仍未完成，正式发布前须另行审核。历史业务内核限制另保存在工程文档，不能以本页替代那些限制。
