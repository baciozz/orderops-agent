## 操作与数据范围

按根目录锁文件安装，使用新的本地合成目录；不要对真实生产数据库运行初始化或 seed。示例沿用仓库源码启动方式：

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.lock
.venv/bin/python -m pip install --no-deps -e .
mkdir -m 700 local-preview
export OOS_DATABASE_URL="sqlite:///$PWD/local-preview/review.db"
export OOS_LIVE_ENABLED=false
.venv/bin/python -m app.cli init-db
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000/ui/reviews`。无需 seed；示例只是合成快照和需求，解析器没有登记对应答案。当前导入格式为明确JSON快照与文本，七种G2输入形式仍待完成。选择快照中的订单号→保存→提取或人工输入→核对逐行差异→确认清单→下载CSV/XLSX。

新工作区是 `review_workspace` 独立表，没有指向可执行 Plan/Approval/Operation 的转换，也没有提交业务入口。确认只表示用户已核对清单；不预占库存、不修改订单、不联系供应商、不提交ERP。旧 `/ui` FIXTURE 业务演示保留独立入口和审批/提交行为，不能把真实导入资料自动搬入那里。

库存是快照中可用量，不是本系统实时读数。缺少已发量、受影响现货SKU可用量、生产已裁量或关联生产采购单时阻断确认；未知不等于零。版本、数量、引用和动作经确定性检查；原始模型提案及人工替换理由分开保存。核对只依据导入资料，不证明资料真实、完整来源或共享依赖闭包；MTO下游只是待人工核对的处理提示，没有生成可执行采购/生产单。

## 真实模型入口

沿用服务端 `OOS_LIVE_ENABLED`、provider/model/baseURL、运行时密钥、单价、预算、timeout、每任务调用数配置。页面显示提供方/模型/预算，调用前必须确认传输范围。输入/输出结构见 `app/review/contracts.py`，提示词版本 `local-review-v1`。真实调用复用既有预算账本；按工作区ID记录 `agent_id`，本切片另在工作区事务内限定总尝试数。全库预算上限仍取配置与硬上限$5的较小值；产品中的默认$5不自动构成使用者授权；本轮另外取得了$5授权，见[接入与费用计划](REAL_MODEL_ACCESS_AND_BUDGET.zh-CN.md)。

未就绪时在领取尝试前返回 `REVIEW_MODEL_NOT_READY`，不发送资料、不耗调用次数、不回退FIXTURE。超时、网络错误或响应无效后保留原资料与安全错误码，不生成可确认的半成品。超时可能已计费，悲观账本保留；自动重试为0，需要用户明确新调用标识，默认每任务最多3次。无费用授权不得运行付费测试。

本轮已获OpenAI/$5授权，计划固定gpt-6-luna；凭据安全注入与API网络许可仍待完成，真实模型与同模型基线评测均未执行。测试内 `offline-mock-NOT-a-real-model` 和 MockTransport 明确只是本机模拟协议，不计入模型能力。模型传输环境的代理/网络通达性还需在实际提供方被授权后验证。

## 纠正、版本、取消与恢复

- JSON API支持多动作提案；当前HTML人工表单明确替换为单项动作，不能把它当作完整多行编辑器。
- 资料、库存快照或澄清更新时保存上一版，移除当前提案，作废清单确认。必须重新提取或人工纠正再确认。
- 纠正只替换提案，不改原需求；人工输入不会伪称模型引用。
- 同一收件标识+相同资料返回原任务；同标识不同资料拒绝。同提取标识不重复调用，失败也不自动重发。相似新标识的语义重复提示仍待实现，不能把请求去重叫作语义去重。
- 模型调用不持有数据库写锁；事务保留nonce与版本。取消、新资料或超时恢复后，迟到响应不能恢复旧提案。账本可能仍记录已发生费用。
- 重启后任务仍可找回；RUNNING需等模型时限加60秒缓冲后显式恢复为ERROR，再由用户决定重试。恢复不自动重发。
- 工作区取消只终止清单处理，不撤回外部调用或已下载文件；本入口没有业务提交可撤销。
