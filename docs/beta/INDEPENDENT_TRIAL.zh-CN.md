# 独立使用者试用准备（尚未执行）

这份材料是AI准备的交接清单，不是用户反馈。参加者须未参与本项目开发；由所有者自行选择、说明开发预览状态并安排试用。本任务不邀请人员、不发送文件、不创建账号或开放共享服务。实际参加者、耗时、困难、协助和结果均保持空白，不能由开发者或AI代填通过。

## 所有者准备

1. 选择经核对的私有源码候选，保留MANIFEST、提交SHA、操作系统和Python版本。安装路径使用[README](../../README.md)及[本机指南](../LOCAL_BETA_GUIDE.zh-CN.md)，不要临时口头补齐缺失步骤。开发侧安装成功不代表陌生用户也成功。
2. 提供以下已存在的合成开发资料，便于参加者直接找到文件：`tests/fixtures/review_development/pdf-wrapped/baseline.json`与`request.pdf`。这是已用于开发的PDF场景，供可用性观察，不作盲测或泛化评测；不包含新正式保留集。
3. 默认关闭LIVE、不配置密钥，仅监听127.0.0.1。独立干净安装的无密钥预演只能验证导入、人工纠正、确认和导出。它不能冒充包含真实提取的完整G4验收。
4. 完整真实提取试用须先由协调者安排受控本机环境、已有安全模型配置和同轮费用账本。密钥不交给参加者、不填浏览器、不录入试用记录；不能为每人新建费用库后重新获得本轮$5额度。该前置条件未就绪时，真实提取步骤标阻塞，不能由模拟响应替代。
5. 不使用真实订单或客户聊天，不启动共享网络入口，不要求参加者改数据库或忽略错误。观察者除安全中止外尽量不引导；需要协助时记录具体协助再继续。

## 给参加者的任务说明

你正在试用本机订单变更清单的开发预览。它只生成建议，不执行订单或修改ERP。

- 按随附说明安装、初始化并打开清单入口，记录首次依赖下载、安装配置和实际处理任务的时间。
- 导入提供的合成基线，明确选择订单SYN-3404；上传客户PDF并确认其用途、关键字段和完整上下文。以PDF中的要求为准，不猜测不明确的事实。
- 只有所有者已完成真实模型和费用准备时才进行真实提取，记录实际结果。若模型追问，先对照原件；可追加澄清，也可人工纠正。人工完成必须单独记录，不算模型提取成功。无密钥预演直接使用明确标记的人工输入路径。
- 检查哪些行真的变化、哪些行保持原值，确认清单，下载CSV和XLSX。关闭页面后从列表找回结果，再说明“订单是否已经执行”。
- 遇到错误或不理解的地方可以停下、记录、请求协助；不要求为了完成任务绕过限制。

## 观察者记录与核对

使用[空白记录](INDEPENDENT_TRIAL_RECORD.json)。不用真实姓名、邮箱或联系方式；参加者代码由所有者填写。不得录下凭据、账户余额或其他个人窗口；没有参加者另行授权时不收集录屏或截图。

观察内容包括：是否能找到入口、基线和来源确认是否易懂、模型实际表现、能否发现并处理多余澄清、是否理解原始提案与有效差异、人工纠正后是否知道需要重新确认、两种导出能否打开、找回任务是否需要协助。下载、安装、模型等待、人工处理及中断时间分别记，不把安装时间塞进五分钟演示。
